## Creación manual posterior

1. Abrir Firebase Console con la cuenta del propietario, elegir **migapos → Firestore Database → (default) → Índices**. Revisar primero el conjunto activo y sus exenciones de campos simples.
2. Consultar la fila por módulo/ID. Para un compuesto necesario ausente, usar **Añadir índice** con la colección, ámbito y campos ASC/DESC exactos de la tabla Ixx. Los campos de igualdad pueden estar permutados en un índice compatible ya existente; no crear duplicados a ciegas.
3. `__name__` es el orden documental implícito: coincide con la última dirección de ordenación salvo que la tabla indique otra dirección. No agregar otro campo artificial ni cambiar el ámbito.
4. Esperar a que Console indique **Habilitado** y reintentar únicamente el flujo afectado. Si el SDK entrega un enlace real, la app puede mostrarlo; esta guía no fabrica URLs create_composite.
5. Registrar manualmente Pendiente / En creación / Habilitado y fecha de comprobación al final de la guía. Conservar índices históricos mientras se revisan clientes desplegados. No desplegar este archivo completo ni aceptar eliminaciones automáticas de índices activos.
