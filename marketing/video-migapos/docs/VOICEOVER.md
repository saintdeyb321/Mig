# Locución y subtítulos

Español claro, tono de conversación y pausas cortas entre escenas. Pronunciar MigaPOS como «Miga Pos». El primer montaje será silencioso con texto visible. Las entradas se ajustarán a la grabación si se autoriza voz.

| Entrada | Salida | Locución y texto del subtítulo |
|---|---|---|
| 00:00.000 | 00:02.800 | Tu tienda, bajo control. |
| 00:03.200 | 00:05.500 | Arma el ticket |
| 00:05.500 | 00:07.800 | y revisa el total antes de cobrar. |
| 00:08.200 | 00:12.800 | Busca un producto y consulta cuánto stock queda en tu sede. |
| 00:13.200 | 00:17.800 | Revisa tus ventas del período desde el tablero. |
| 00:18.200 | 00:20.500 | Al cierre, compara el efectivo contado |
| 00:20.500 | 00:22.800 | con el monto esperado. |
| 00:23.200 | 00:26.600 | Conoce MigaPOS. |
| 00:27.000 | 00:30.000 | Solicita una demostración. |

Cuando titular y locución coincidan, usar el titular como subtítulo para evitar duplicación. En las demás escenas, mantener hasta dos líneas, con cortes en límites de frase. Trasladar los tiempos a `startMs` y `endMs` en JSON para la composición. La locución queda pendiente de una grabación autorizada.
